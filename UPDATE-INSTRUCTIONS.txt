Read AI-SETUP.md. Back up your project/database, stop servers, and extract this archive into the existing medical-system folder. Merge custom edits before replacing matching source files. Run python manage.py migrate from backend with your existing activated medical_env and DEBUG=1. Download Ollama and run ollama pull qwen3:8b (or qwen3:4b). Set OLLAMA_MODEL accordingly in the Django terminal and restart Django. Start frontend with pnpm dev --port 5174. Open AI Agent as a doctor or admin. No database or environment is included in this ZIP. No new package dependencies are required. Clinical drafts require the assigned doctor to review and click approval.
